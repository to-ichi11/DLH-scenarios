# 砂漠の盟友｜GMダッシュボード

『デッドラインヒーローズRPG』キャンペーン第2話 v13.0 に対応するGM専用ページです。

- 進行、ロケーション、イベント、手掛かり、フラグ、NPCのエンパシーを管理します。
- シナリオ本文はv13.0から収録。敵データは原稿どおり未設定です。
- 進行データはブラウザのlocalStorageに保存し、JSONで書き出し／読込可能です。
- フラグとイベントの処理はGMが操作します。シナリオの未訪問イベントを自動発生させません。
- GitHub Pagesを公開するとサイト本文は原則公開されます。GMネタバレが含まれます。

## 公開方法

リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** で `gh-pages` の `/(root)` を選択します。非公開リポジトリから公開する場合は対象GitHubプランの要件に注意してください。

既存の `main` ブランチのシナリオ本文・ファイルには変更していません。
