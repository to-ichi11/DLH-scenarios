# DLH-scenarios

このリポジトリは、日本語TTRPGシナリオ
『アサクサの休日』
『黄昏の残響』
『午前零時の銀河鉄道』
を中心としたシナリオ置き場です。

三作はそれぞれ単体でも扱えますが、連続した三部作キャンペーンとして遊ぶことで、人物関係や感情の流れ、伏線と余韻がより強く響く構成になっています。

## キャンペーン案内

キャンペーンでは、物語は以下の順番で進行します。

1. 『アサクサの休日』
2. 『黄昏の残響』
3. 『午前零時の銀河鉄道』

物語は、夕焼けの東京から始まり、黄昏の街を抜け、やがて深夜の銀河へと至ります。
一見すると別々の事件に見える三つの出来事は、少しずつ互いに響き合い、三人のPCを同じ夜の中心へと導いていきます。

キャンペーンで遊ぶ場合、各シナリオのエントリーは自由選択ではなく固定です。

### 固定エントリー

- PC1
	- 『アサクサの休日』共通エントリー
	- 『黄昏の残響』エントリー1
	- 『午前零時の銀河鉄道』エントリー1

- PC2
	- 『アサクサの休日』共通エントリー
	- 『黄昏の残響』エントリー2
	- 『午前零時の銀河鉄道』エントリー2

- PC3
	- 『アサクサの休日』共通エントリー
	- 『黄昏の残響』エントリー3
	- 『午前零時の銀河鉄道』エントリー3

### PCの立ち位置

- PC1：使命と責任を背負い、人々を守るために前へ立つPC
- PC2：喪失した大切な誰かをめぐる想いを抱えて進むPC
- PC3：夢、予兆、境界の気配にもっとも近い場所へ導かれるPC

配役や雰囲気づくりの詳細は [キャンペーン情報.txt](キャンペーン情報.txt) を参照してください。
